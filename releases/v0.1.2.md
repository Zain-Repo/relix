# Relix 0.1.2

- Add background release checks and verified portable update downloads.
- Offer a restart to install newer stable releases while protecting active
  database work, open transactions and unsaved query drafts.
- Verify exact platform assets using GitHub's HTTPS release metadata and SHA-256.
- Include upgrade instructions for 0.1.0 and 0.1.1, which require one manual
  upgrade before they can use the updater.

## Known limitations

Packages have no independent publisher signatures. macOS bundles use ad-hoc
signing without Apple notarization. Automatic updates require a supported,
writable portable installation. Linux runtime prerequisites remain in
docs/releases.md. Windows replacement, rollback and native relaunch were validated
using disposable installations. Native Linux and macOS update/restart testing
and a published older-to-newer release pair remain to be validated.
