# Relix 0.1.1

- Fix release publication by verifying draft uploads through GitHub's release ID.
- Decode CLI responses as UTF-8 when recovering releases from Windows.
- Add regression coverage for draft lookup failures and Unicode command output.

## Known limitations

Packages are unsigned. macOS bundles use ad-hoc signing without Apple notarization.
Linux requires the runtime libraries listed in docs/releases.md. There is no
automatic updater or installer. CI tests do not replace interactive desktop,
live PostgreSQL/MySQL or unlocked OS credential-store testing.
