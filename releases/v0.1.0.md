# Relix 0.1.0

- Native database workbench for SQLite, DuckDB, PostgreSQL and MySQL.
- Independent SQL tabs, schema inspection, query execution and cancellation.
- Table browsing, result exports and reviewable import and record-edit SQL.
- Saved connection profiles, queries, history and OS credential storage.
- PR validation and native Windows, Linux and macOS release packages.

## Known limitations

Packages are unsigned. macOS bundles use local ad-hoc signing without Apple
notarization. Linux requires the runtime libraries listed in docs/releases.md.
There is no automatic updater or installer. Headless UI tests do not replace
interactive testing on each supported desktop. CI does not connect to live
PostgreSQL or MySQL servers or probe an unlocked OS credential store.
