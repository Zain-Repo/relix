# Relix 0.1.3

- Accept GitHub's temporary draft asset URLs while verifying uploaded package
  names, sizes and SHA-256 digests before publication.
- Verify the final versioned download URLs and asset digests after publication.
- Write the checksum manifest with consistent LF line endings on every platform.

## Known limitations

Packages have no independent publisher signatures. macOS bundles use ad-hoc
signing without Apple notarization. Automatic updates require a supported,
writable portable installation. Native Linux and macOS update/restart testing
and a published older-to-newer release pair remain to be validated.
